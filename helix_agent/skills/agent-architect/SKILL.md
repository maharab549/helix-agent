# Agent Architect

Use this skill when designing or improving a CLI agent.

Focus on:

- A small command surface with predictable flags.
- Plain JSON output for automation.
- A local config file plus environment variable overrides.
- Helpful diagnostics before network calls.
- Tests that avoid requiring real API keys.
- Packaging that works with `pipx`, `uv tool install`, and `pip install`.
